模型模式状态耗时详情

设置

轮询 · 签到 · 上游

多账号轮询

多账号时每次请求自动切换账号分摊用量。顺序轮换＝按账号列表轮着用； 优先低消耗＝优先用剩余积分最多的账号。只有 1 个账号时此项无效（按钮置灰）。

签到与上游

签到间隔＝一键签到时相邻两个账号之间的等待秒数（错峰防风控）； 自定义上游＝覆盖 Trae API 网关地址，日常请留空用默认值。
账号安全：每账号并发上限 2；失败回合不会自动重放（防重复扣分）； 模型表有 TTL 缓存，不会逐请求打上游；积分列为按模型费率的估算值（带 ≈）。
